# Blender 3D Models

A personal collection of 3D models created in Blender — ranging across various themes, styles, and experiments. Each model is available as an `.stl` file for 3D printing or further use, alongside rendered preview images.


## Using the Models

The `.stl` files are ready to use — import them into any slicer or 3D software directly.

1. Download the `.stl` file of your choice
2. Open in your preferred slicer or modeling software
3. Print or modify as needed

## 🛠️ Made With

- [Blender](https://www.blender.org/) — modeling & rendering
- Cycles / EEVEE — render engine
